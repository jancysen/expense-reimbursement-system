# Expense & Reimbursement Management System

A full-stack Expense Reimbursement Management System that simulates real-world enterprise finance workflows with role-based approvals.

## Features
- Employee submits expenses
- Manager approves expenses
- Admin marks expenses as paid
- Multi-stage workflow: Pending → Approved → Paid

## Tech Stack
Frontend: React, TypeScript  
Backend: Node.js, Express, TypeScript  

## Project Structure
expense-reimbursement-system
- backend
- frontend

## Expense Workflow
Employee → Submit → Pending  
Manager → Approve → Approved  
Admin → Pay → Paid  

## How to Run

Backend:
cd backend  
npm install  
npm run dev  

Frontend:
cd frontend  
npm install  
npm start
